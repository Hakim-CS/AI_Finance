Title
-Adaptive Budget Allocation Using Machine Learning and Software-in-the-Loop Control Simulation
-“Adaptive AI-Based Budget Control Using Software-in-the-Loop Simulation for Personal Resource Management”
-“AI-Based Adaptive Resource Management Using Predictive Modeling and Closed-Loop Budget Control”


Problem Statement
Personal finance applications often provide static budgets or descriptive analytics, but they rarely evaluate budget recommendations as a control problem. A static monthly budget may be stable, but it does not adapt to changes in spending behavior. Pure machine learning prediction may fit expected expenses more accurately, but it can produce unstable budget changes from month to month. This thesis investigates whether a lightweight adaptive controller can improve the practical behavior of AI-based budget allocation by balancing prediction accuracy, overspending reduction, and budget stability.

Aim
The aim of this thesis is to design, implement, and evaluate a software-based adaptive budgeting system that uses machine learning predictions as input to a control logic layer. The system will be evaluated in a software-in-the-loop simulation using synthetic user spending profiles.

Research Question
Can a machine-learning-assisted adaptive controller provide a better trade-off between budget tracking accuracy, overspending prevention, and budget stability than static budgeting or direct ML prediction alone?

Objectives

Develop a full-stack personal finance application with expense tracking, budgeting, loans, and AI-assisted budget recommendation features.
Train and compare machine learning models for category-level expense prediction.
Design an adaptive budget controller that combines predicted expenses, previous budget state, income constraints, and saving targets.
Evaluate static budgeting, last-month budgeting, direct ML prediction, and adaptive control in a software-in-the-loop simulation.
Analyze the trade-off between accuracy, overspending rate, and stability from a Mechatronics/control-systems perspective.
Academic Positioning
Although the application domain is personal finance, the academic framing is closer to Mechatronics through control logic rather than physical hardware. In Mechatronics, systems often combine sensing, prediction, actuation, feedback, and control under constraints. In this project, expense history acts as the sensed signal, predicted spending acts as the forecasted disturbance, the budget allocation acts as the control output, and the saving target/income ceiling acts as a constraint. The system is therefore studied as a simulated control process, not merely as a web application.

Methodology
The backend is implemented using Node.js, Express, TypeScript, and Prisma. The frontend is implemented using React and Vite. The AI component is implemented in Python. Synthetic financial data is generated using multiple user personas over several months. Machine learning models are trained to predict future expenses per category based on income, month, previous spending, and total previous expense behavior.

The main experiment compares four strategies. The first is a static budget based on fixed category percentages. The second uses the previous month’s spending distribution. The third directly applies machine learning predictions as the budget distribution. The fourth uses an adaptive controller that smooths machine learning predictions with the previous budget state and scales the result according to income and saving target constraints.

The evaluation uses tracking error, overspending rate, allocation accuracy, and budget stability. These metrics allow the thesis to compare not only prediction performance but also control behavior. This is important because a budget system should not only be accurate; it should also avoid sudden unrealistic changes.

Expected Contribution
The expected contribution is not a new ML algorithm. The contribution is the design and evaluation of a bachelor-level adaptive financial control architecture where ML prediction is integrated with control-inspired budget regulation. The thesis demonstrates how a consumer finance system can be reframed as a software control problem and evaluated using simulation-based methods.

Limitations
The evaluation uses synthetic data, so the results cannot be claimed to generalize to real users. The system does not model human behavioral response to budget recommendations, which means it is not a full closed-loop behavioral control system. The controller is intentionally simple and suitable for bachelor thesis scope. These limitations will be explicitly discussed instead of hidden.

Expected Outcome
The expected result is that direct ML prediction achieves the best tracking accuracy, while adaptive control provides a more stable and practically usable budget allocation. The thesis will argue that the adaptive controller is valuable because it reduces volatility while maintaining much of the benefit of ML prediction.
